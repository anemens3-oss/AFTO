## 2. Технологический стек

Проект реализован **строго без сторонних библиотек и фреймворков**:
* **HTML5** — семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<dialog>`, `<footer>`), доступность (ARIA, клавиатурная навигация, `skip-link`), SEO и Open Graph метатеги.
* **CSS3** (`styles.css`) — модульная система CSS-переменных, адаптивная сетка CSS Grid / Flexbox, табличные цифры (`font-variant-numeric: tabular-nums`), поддержка `prefers-reduced-motion: reduce`.
* **Vanilla JavaScript ES6+** (`script.js`) — чистые экспортируемые функции фильтрации и расчёта (покрытые unit-тестами `node:test` в `script.test.js`), интерактивная матрица 12 категорий услуг, живой поиск по прайс-листу, локальный калькулятор-ориентир стоимости работ, модальная галерея Lightbox и адаптивное мобильное меню.

## 4. Публикация на GitHub Pages

Все ссылки между страницами (`index.html`, `prices.html`) и пути к локальным ресурсам (`styles.css`, `script.js`, `assets/images/...`) написаны в **относительном формате** без ведущего слэша, поэтому сайт корректно работает как в корне домена, так и в подпапке репозитория `https://<username>.github.io/<repository>/`.

1. Загрузите файлы репозитория в ветку `main`.
2. Перейдите в `Settings → Pages` вашего репозитория на GitHub.
3. В разделе **Build and deployment** выберите `Deploy from a branch`, укажите ветку `main` и папку `/ (root)`.
4. Нажмите **Save**.
